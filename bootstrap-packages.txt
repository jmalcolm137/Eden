# Source templates required by `./cbuild source-bootstrap`.
#
# This is the stage 0 + stage 1 dependency closure of main/base-cbuild, with
# stage 1 and stage 2 having the same dependency set. It is what cbuild
# actually needs to build the bootstrap environment from source.
#
# It deliberately excludes stage-3-only convenience dependencies. In
# particular, upstream base-cbuild adds `ccache` at stage > 2; ccache's
# runtime closure pulls elfutils -> libmicrohttpd -> gnutls -> unbound ->
# protobuf -> boost, plus util-linux, trousers, etc. Those are not needed to
# bootstrap, so this tree applies a local patch dropping that one dependency
# (see patches/). With it, stages 0-3 need the same 66 templates.
#
# Keep this sorted. One source template directory name per line, relative to
# main/.
